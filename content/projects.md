## [virby-nix-darwin](https://github.com/quinneden/virby-nix-darwin)
a module for nix-darwin that configures a lightweight, vfkit-based linux VM as a remote build machine for nix, allowing linux packages to be built on macOS.

## [nixos-asahi-package](https://github.com/quinneden/nixos-asahi-package) (archived)
a package that enables easy installation of NixOS onto bare metal Apple Silicon Macs using the asahi-installer and derivations from nixos-apple-silicon.
